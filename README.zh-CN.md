# 墨 Sumi

[English](README.md) · [日本語](README.ja.md)

一个可编辑汉字路径、曲线、笔压、笔触类型和笔顺的书法编辑器，通过毛笔模拟生成循环 GIF。可用于教学材料、笔顺演示、插画等项目。

**在线版本：** [sumi-kanji-editor.grok.me](https://sumi-kanji-editor.grok.me/)

## 本地运行

使用 Node.js 22 和 npm：

```sh
npm ci
npm run dev
```

打开 http://localhost:8080/。如果端口 8080 已被占用，启动会失败。

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

项目使用 React、TypeScript、TanStack Start、Vite、Tailwind CSS v4 和 Nitro。生产构建面向 Vercel，输出到 `.vercel/output`。目前 `npm run preview` 无法预览这种生产输出；本地编辑请使用开发服务器。

本地运行由 PGLite 提供数据库，无需配置数据库或登录。使用 Postgres 时设置 `DATABASE_URL`；配置后，构建会执行 SQL 迁移。在线版本的 Google/X 登录使用 Grok 认证集成，部署到其他环境时需要另外配置认证。

## 编辑与导出

输入一个汉字或短词组，选择 Kaisho、Wet、Dry、Goat 毛笔并调整参数。打开 **Edit** 编辑路径和标记，点击 **GIF** 导出动画。

GIF 包含当前曲线、笔顺、标记、毛笔设置、速度、网格和参考轮廓。**Export paths** 将编辑配置下载为 JSON；目前没有 JSON 导入功能。

编辑内容保存在当前浏览器的本地存储中，不会在浏览器之间同步。登录后可用的 **Save** 保存收藏字符，不是路径导出功能。

| 操作 | 功能 |
| --- | --- |
| Move | 拖动节点移动它；拖动节点之间的线段，将其变成曲线；点击线段插入节点。分割曲线时保持原有形状。 |
| 起点 | 在 Move 模式点击第一个节点，编辑起笔角度和压力。角度以页面为基准。 |
| Earlier / Later | 在 Move 模式选择节点，将整笔向前或向后调整笔顺。曲线和标记一起移动。 |
| Draw | 点击放置节点，双击结束。新笔画添加到笔顺末尾。 |
| Delete | 删除节点或标记。 |
| Suggest | 保留路径和起笔设置，重新推测笔触类型标记。 |
| Reset | 丢弃当前显示字符的编辑，恢复内置默认配置。 |
| Clear | 清空路径，从空白开始绘制。 |

曲线使用二次贝塞尔曲线。路径显示、毛笔模拟和 GIF 导出共享同一曲线。

## 标准模板 永

[`src/lib/brush/yong-template.ts`](src/lib/brush/yong-template.ts) 保存作者编辑的正式 永 模板，包括节点、曲线控制点、标记和正确笔顺，也包含最新的点画 1.35 倍压力及第三笔 1–1.3 倍的压力设置。

没有个人保存的编辑时，载入这个模板。**Reset** 恢复模板；**Suggest** 保留当前路径，只恢复模板的标记布局。个人保存的编辑优先。

| 笔顺 | 笔触类型 |
| --- | --- |
| 1 | 側 Dot |
| 2 | 勒 Horizontal → 努 Vertical → 趯 Hook |
| 3 | 策 Rise → 掠 Sweep left |
| 4 | 啄 Short left |
| 5 | 磔 Splay right |

## 数据库路径整理

原始数据库常把起笔和收笔的外形画进中线。Sumi 用笔触类型和笔压表达这些细节。

- 长度至少为 90 个数据库单位，且超过总长 60% 的部分位于轴线 12° 以内的直横、直竖，可整理为主体的两个原始节点。横画通常约 5° 的上扬会保留。
- 移除小幅起笔、收笔装饰，同时保留明显转折、向上的钩和较大的曲线，包括宀的横钩。
- 整笔判定为 Short left 时，仅对较短且急转的起笔移除最初一两个节点。
- 永 使用正式模板，不依赖数据库整理。

这些规则是启发式推测，其他字符的类型和标记仍可手动调整。除少数明确限定的旧数据修复外，保存的个人编辑优先。

## 笔压与笔触

第一个类型标记决定从起点开始的笔触，后续标记从所在位置切换类型。压力标记对最终笔压施加倍率。

- **Dot：** 从主体笔压的 0.75 倍开始，在路径 75% 处达到 1.35 倍，终点为 1 倍，并形成圆润末端。
- **Horizontal：** 主体压力均匀，自带收笔，无需单独添加 Stop。
- **Vertical：** 停笔时用 Stop 形成圆润末端；带钩时在转折节点放置 Hook。
- **Hook：** 前面的 10% 以非线性方式升至当前压力的 1.5 倍，然后逐渐收尖。
- **Rise：** 起笔和厚度与横画相同，前 20% 之后逐渐减至 0.25 倍。没有横画收笔，低压不会延续到下一种笔触。
- **Sweep left / Short left：** 默认起笔压力倍率为 1 倍，向末端逐渐收尖。

起笔是路径前 20% 内的压力和方向变化，不是在路径之前另画一段。默认角度：Vertical 为 **135°**，Horizontal 和 Rise 为 **110°**，其他为 **160°**。起笔菜单可将压力倍率调整为 **0.25–3 倍**；Horizontal、Vertical、Rise 默认 **1.9 倍**。

横画收笔反向应用起笔的压力变化，并增加约 15% 的压力。横画转入其他笔触时，先在转折前完成收笔，随后在新部分的前 20% 释放额外压力。

压力标记也影响起笔和收笔。Fold 增加转角压力，Lift 逐渐减压收尖。详细数值见 [英文说明](README.md#stroke-types-and-pressure)。

## 毛笔模拟与部署

笔毛使用弹簧和阻尼模拟。笔毛的前移偏移和低压修正随压力连续变化，避免点画在书写途中突然跳动。路径最初 8% 的墨迹会相互融合，平滑粗大笔毛的痕迹，其余部分保留纹理。毛笔朝向与移动方向分别处理，避免扭转和偏离路径。GIF 帧按顺序处理，无需将整个动画保留在内存中。

Grok 的 PWA、预览桥接、认证辅助和 `startup.sh` 服务于当前在线部署。迁移到其他环境时，还需调整构建和认证配置。
