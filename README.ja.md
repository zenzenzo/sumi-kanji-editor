# 墨 Sumi

漢字の書道エディタ。文字を入力し、書き順のパスを編集し、それぞれの線をどのように書くかをピンで指定して、シミュレートされた筆が文字を書くループGIFを書き出せます。

自由に使い、フォークし、必要な部分だけを別のプロジェクトに組み込んでください。このプロジェクト全体を自由に改変・再利用できます。

ライブ版はこちらです： https://sumi-kanji-editor.grok.me/

## なぜ作ったのか

主な用途は、既成の書き順アニメーションではなく、**自分のパス、自分のピン、自分の筆**で完全にカスタマイズした漢字書道のアニメーションGIFを作ることです。

また、漢字の書き方を視覚的に学ぶための教材や、子ども向けの教育コンテンツに組み込むこともできます。単なる書き順表示ではなく、筆の動きや筆圧、払い、止めなどを含めて、漢字が実際に書かれていく様子を表現することを目的としています。

1. 文字（または短い熟語）を選ぶ
2. 筆を選ぶ — 楷書、Wet、Dry、Goat — と各スライダーを調整する
3. 中心線を編集または描画し、永字八法に沿った動きになるようにタイプピンを配置する
4. 書き込みパネルのGIFボタンを押す

ファイルは `sumi-永.gif`（入力した文字に応じて変わります）として書き出されます。グリッド、ゴーストアウトライン、速度、パスの編集内容もすべて記録されます。

**永**はテンプレート文字です。推奨されるピン配置は、実際の書き順の中心線に対する永字八法に基づいています。永を読み込み、必要なら Suggest を押してきれいなピン配置を生成し、他の文字を編集するときの参考にしてください。

## パスエディタ

「Edit path」をオンにすると、書き順の中心線（`hanzi-writer-data` に由来）が表示され、その上を筆の毛束シミュレーションが追従します。

| ツール | 動作 |
| --- | --- |
| Move | 頂点をドラッグします。線分をクリックすると点を追加します |
| Draw | クリックしてノードを配置し、ダブルクリックで最後のノードを配置します。新しいストロークは描いた順番でインクが付着します |
| Delete | 頂点またはピンをクリックして削除します |
| Suggest | ジオメトリからタイプピンを推測します（永には専用テンプレートがあります）。Reset は元の中心線とピンに戻します。Clear はすべてのパスを消去し、白紙から描けるようにします。ゴーストアウトラインと紙は元の文字のフレームを維持し、短い新しい線に合わせてズームしません |

筆は、ドラッグを終了したとき、または描画したパスを終了したときにのみ再シミュレーションされます。

## タイプピン — 永字八法

ストロークにはあらかじめタイプが設定されていません。タイプはピンによって指定されます。最初のタイプピンがストローク全体のタイプを最初から決め、その後に別のタイプピンが置かれた場合は、その位置から次のピンまたはストロークの終点まで、そのタイプが適用されます。筆圧はこのエンベロープに対する倍率であり、タイプを切り替えるものではありません。

デフォルトの本体部分は、筆を最大まで押し付けたときの毛束サイズの50%です。2倍の筆圧で予約された最大値に達します。

| ピン | 英語 | エンベロープ |
| --- | --- | --- |
| 側 | Dot | 約30% → 80%。線ではなく点 |
| 勒 | Horizontal | 50%で一定。横 |
| 努 | Vertical | 50% → 45%、45%を保持、45% → 50%。始筆（着筆）あり |
| 趯 | Hook | 最初の40%は50%を維持し、その後0までテーパー。跳ね |
| 策 | Rise | 始点11% → パスの45%で50%、その後テーパー。着筆なし |
| 掠 | Sweep left | パス全体で約67% → 0、`(1−t)^0.88`（区間開始時の筆圧は通常より約1/3重い） |
| 啄 | Short left | 100% → 0、`(1−t)^1.35`。始筆あり、最大筆圧で着地 |
| 磔 | Splay right | 最初の75%で10% → 100%、その後パス上で0までテーパー |

「Suggest」機能は文字にタイプピンを配置します。ただし、正しいストロークタイプのピンが標準で設定されているのは現在 **永**だけです。別の漢字を選び、それぞれのパスにタイプピンを設定して、意図した書き方になるよう調整してください。タイプピンだけでは望む結果にならない場合は、筆圧ピンを使ってより細かく調整できます。1つの筆圧ピンはストローク全体に適用されますが、複数の筆圧ピンを連続して配置することもでき、その間の変化は滑らかに補間されます。

### 永の推奨配置

| ストローク | ピン |
| --- | --- |
| 1 | 側 |
| 2 | 勒（始点付近）、努（ノード4の直後）、趯（ノード8の直後） |
| 3 | 策（始点付近）、掠（ノード6の後） |
| 4 | 啄 |
| 5 | 磔 |

策と掠が接続する場合、策の上昇は掠ピンまでしか続きません。掠がその位置からパスの残りを引き継ぎ、掠ピンで突然消えることはありません。

**着筆（pre-path）**は、努・勒・啄がベクトルに沿って動き始める前に行われる、短い「傾けて筆を落ち着かせる」動作です。編集可能なパスにはこの動きは含まれません。

## 仕上げ・アクセントピン

| ピン | 動作 |
| --- | --- |
| 圧 Pressure | タイプに対する倍率。1つのピンならストローク全体に適用され、2つのピンならその間を補間します（最初の値は始点から、最後の値は終点まで維持されます） |
| 折 Fold | 折れ。予約された最大筆圧を使い、角の外側をマイター処理して鋭い角を作ります |
| 止 Stop | 止め。92%以上を維持し、終点を少し通り越して折り返し、涙滴状の溜まりを作ります |
| 払 Lift | 払い。ピン以降、残りのパスの終わり近くで厚みが一点に収束します。毛束は密集し、櫛のように毛が単純に浮き上がるわけではありません |

タイプピン以降のパスの色は、そのタイプに対応した淡い色になります。そのため、タイプを連続して切り替えた場合も視覚的に確認できます。

## 筆

Sizeスライダーは、筆を最大まで押し付けたときの接地範囲を表します。筆圧によってその範囲が変化するため、払いでは毛が密集していき、紙に接触する毛も中心から外側へと変化します。これはKritaのブラシにおける毛のScaleや、Photoshopの毛筆ブラシのsplayと同じ考え方です。

プリセット：

- **Kaisho**（オオカミ毛）
- **Wet**
- **Dry**（飛白）
- **Goat**（柔らかく、方向転換時に遅れて追従）

Size、毛の本数、開き具合（splay）、墨量、硬さ（stiffness）、柔らかさをリアルタイムで調整できます。

Wetの隙間埋めは、現在書いているストロークごとに行われます。別のストロークをまたいで埋めることはないため、本来空けておくべきストローク間の紙の部分はそのまま残ります。

## 実行

```text
npm install
npm run dev
```

その後、Viteが表示するURLを開いてください（デフォルトは `http://localhost:8080`）。

```text
npm run build      # プロダクションビルド
npm run typecheck
```

Node 22。使用技術は TanStack Start、Vite、Tailwind v4。認証とオプションの「お気に入り」テーブルにはPostgresを使用しています（本番環境ではNeon、ローカルではPGLite）。Google / Xでサインインすると、お気に入りの文字を一覧として保存できます。パスの編集内容はブラウザ上で保持されます。

## 再利用

MITライセンスです。リポジトリをコピーし、`src/lib/brush/`を別のプロジェクトに取り込み、紙の表現を変更し、UIを削除するなど、自由に利用できます。許可を取る必要はありません。

フォークを公開する場合、自分のREADMEでこのプロジェクトに触れてもらえれば嬉しいですが、必須ではありません。`hanzi-writer-data`から書き順の中心線を読み込んでいる場合は、そちらの帰属表示を残してください。

## 構成

```text
src/lib/brush/     毛束シミュレーション、Wet-paper処理、パスピン、ストローク準備、GIF書き出し
src/lib/kanji/     文字データの読み込み、プリセット
src/components/    スタジオ、紙、パスエディタ、ツールバー
src/routes/        ページと認証
```

筆の部分を別のプロジェクトに取り込みたい場合に興味深いファイル：

- `src/lib/brush/bristles.ts` — 毛束の物理、筆圧に応じた広がり、スタンプ
- `src/lib/brush/wet.ts` — ストロークごとの隙間埋め（ストローク間では行わない）
- `src/lib/brush/engine.ts` — 着筆、止めのフック、折れのマイター処理、磔のエンベロープ
- `src/lib/brush/edits.ts` — ピン、連続指定、永テンプレート
- `src/lib/brush/gif-export.ts` — 同じプレイヤーからループGIFを書き出す
